Bank Account System

Project Overview

Bank Account System is a console-based Java application developed to simulate basic banking operations through a simple menu-driven interface. The project demonstrates important Core Java concepts including Object-Oriented Programming, Encapsulation, Inheritance, Exception Handling, Collections, and File Handling.

Technologies Used

- Java
- Core Java
- Object-Oriented Programming
- Collections Framework
- Exception Handling
- File Handling
- Input/Output Streams

Features

- Customer management
- Savings Account management
- Current Account management
- Banking transactions
- Loan management
- Staff login
- Complaint and ticket management
- Account locking and security handling
- Exception handling
- Transaction logging
- Failed login tracking
- Console output handling

Java Concepts Used

- Classes and Objects

File Handling

File Handling is used in the application to store and manage application-related information.

- "accounts.src" – Account-related stored data
- "objcust.src" – Customer-related stored data
- "failed_logins.txt" – Stores failed login information
- "console_output.txt" – Stores console output generated by the application

Exception Handling

The project includes custom exceptions to handle banking-related errors, including:

- "AccountLockedException"
- "InsufficientBalanceException"
- "InvalidAccountException"

How to Run

1. Download or clone this repository.
2. Open the project in Eclipse or another Java IDE.
3. Make sure the Java source files are placed inside the appropriate package.
4. Run "BankApp.java".
5. Follow the options displayed in the console.
